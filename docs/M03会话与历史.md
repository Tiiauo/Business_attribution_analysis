# M03 会话与历史阶段

当前状态：M03 模块验收通过。会话管理、历史读取、附件上传/下载/隔离解析、每轮选择、任务输入清单和单附件异步清理已完成；跨模块任务竞争、真实产物来源及整会话清理分别由 M04/M05/M06 继续联调。

## 页面

登录后访问 `/workbench`。左侧新建/切换本人会话，筛选活跃/归档；中间维护名称和空会话的数据源，读取历史与更早消息，归档/恢复；右侧保留分析结果位置，不填充演示答案。刷新在当前用户的 sessionStorage 中恢复选中会话和分类，M04仅保存未发送草稿，历史与凭证不缓存。

首次接受用户消息后，源锁定由已有用户消息派生，归档/恢复和任务失败不会解锁。源停用保留原绑定和历史，不能自动改为其他源。消息接受和自动标题由 M04 实现；M04现已接通真实发送/排队/取消/恢复，见[任务说明](M04任务与实时.md)。

## 接口

沿用登录 Cookie、同源 Origin 和 X-CSRF-Token。所有会话读写按真实用户归属校验，管理员也不能跨用户读取；未知和越权统一 404。ID 使用正整数字符串。

| 方法与路径 | 契约 |
| --- | --- |
| POST /api/chat/create | `{title?,data_source_id?}`；空白标题为“新会话”/default，显式标题为 manual，可不选源 |
| POST /api/chat/update | `{conversation_id,title?,data_source_id?}`，至少一项；标题去首尾空白、1—100 Unicode 码点；选源仅 active 空会话可更换且须已发布启用 |
| GET /api/chat/ls | `status=active/archived/deleted`、page_size 默认 50/最大 100、cursor；返回 items/next_cursor |
| GET /api/chat/ls/{id} | page_size 默认 50/最大 100、cursor；返回 conversation/items/next_cursor/snapshot_max_seq_no |
| POST /api/chat/archive | `{conversation_id}`；任务未结束→附件删除中→删除失败→解析中依次阻止；重复请求无重复归档副作用 |
| POST /api/chat/restore | `{conversation_id}`；保留源、锁定和历史；重复恢复无重复副作用 |

元数据包含 id 与兼容原接口的 conversation_id、标题来源、状态、源名称/当前状态/锁定、当前与最近任务 ID、last_message_at、清理字段及 can_retry。列表按最后消息时间（空会话用创建时间）与 ID 降序，不因改名提升 last_message_at。所有修改锁定同一会话，后续发送/附件写入须沿用该锁。

历史首次读取固定序号上界，取最新一页，items 升序；下一页保留上界并向更早的排他 before_seq_no 翻页，不把新增消息混入旧分页。非法游标、跨会话游标和 page_size 越界为 INVALID_CURSOR。工具消息保留名称/调用 ID/状态/输入/产物及部分正文；附件历史使用接受时快照，原件缺失仍保留名称、上传时间、解析选项等元数据，并动态标记不可用。

切换会话或刷新读取时使用视图代次丢弃迟到响应；列表分页也校验代次。实时订阅、任务快照与5秒补偿现由M04接入，详见[任务说明](M04任务与实时.md)。

附件初次上传后进入 pending/parsing，前端每 2 秒按会话查询并在终态停止；刷新后重新装载列表继续轮询。附件默认不选，只有解析成功且不在删除流程中的文件可以勾选为本轮输入。上传进度只表达传输，达到 100% 不表示解析完成。
