# 源码仓库范围

本仓库交付运行和维护本项目必需的内容：前后端及独立认证源码、依赖锁文件、迁移、契约、测试、Compose/Caddy/Docker配置、启动与验收脚本、六场景合成种子及演示输入、原型、需求与操作文档。

七模块保留选定的阶段报告，最终交付报告汇总本次实际验证；历史失败批次、原始截图、日志、完整结果快照和备份留在本机验收归档，不批量上传。历史报告中的原始证据路径可能仅在原验收工作区可用，可通过仓库的验收脚本重新生成；仓库中的报告摘要不代替实际重跑。

以下内容不提交：

- `.env`、`.secrets/`、签名和加密密钥、模型凭证、随机账号密码、证书私钥。
- `data/`、`.run/`、数据库/文件卷备份、真实会话及附件、令牌、进程和运行日志。
- `.venv/`、`node_modules/`、`.tools/`、`frontend/dist/`、缓存和浏览器测试输出。
- `待删除文件/` 中保留的中间产物，以及一次性截图和调试脚本。

`.env.example` 仅含占位示例。新环境应按 README 生成独立凭证；恢复已有环境须单独安全交接完整备份及配套密钥。验收命令可能重启本项目服务或发起真实模型调用，执行前核对运行任务与剩余预算。

提交前逐项审阅暂存文件、检查已知凭证与密钥格式，确认没有把本机私密运行目录带入提交。提交后以远端分支提交号复核推送结果。
