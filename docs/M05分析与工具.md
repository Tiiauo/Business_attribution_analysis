M05 模块验收通过。真实模型、SQL/文件工具、附件安全输入、历史证据、上下文摘要和最终报告已完成；物理导出与整会话清理由 M06 验收。

管理页采用 base_url、模型名称、api_key。已配置密钥显示密码遮掩符号，原值不返回；替换保存更新，清空保存移除。测试连接使用当前表单及新输入或已保存密钥发起最小真实请求，显示耗时和错误，不保存/发布配置，可能产生少量费用。TLS 同时信任系统证书与部署本地CA。

使用 Chat Completions SSE/function tools，base_url 自动补 `/chat/completions`；当前不支持 Responses-only 协议。最多16轮交互，其中最多12轮探索，最后4轮只开放结果提交及结构纠正；预算耗尽前以已有证据形成完整结果，缺失项如实说明，不强行补造。调用与任务时限按配置快照；失败、限流、截断、中断、超时均明确失败，不模拟降级。AnalysisOutput 共享 Schema 约束六部分、数值/空值、未知原因、至少两条不同建议及七字段证据。拒绝未知证据、改写摘录/定位、跨会话/失败任务/错误顺序引用、无新证据提高置信；历史关联递归核对到实际工具记录。建议可用换行、分号或常见编号区分。指标值只接受单个数值或null，两期值分别登记；结构校验失败向模型返回最多8项字段路径及错误类型，不回传无效输入值，允许在原有调用/上下文预算内纠正，仍不放宽证据一致性校验。校验拒绝后，后续模型请求只保留提交调用ID、结构化错误及重新提交提示，省略无效草稿参数，避免每次重提都重复占用窗口；原始工具记录、登记证据及已保存过程正文保留。

模型内部的 `submit_analysis` 使用精简证据引用，每项仅含 `evidence_id`、`related_metric`、`confidence`。后端只从本任务及获准历史的登记证据中补齐来源名称、类型、摘录和定位，再按原AnalysisOutput/七字段证据规则校验并保存；对外API及前端契约不变。未登记ID、引用中夹带来源字段、重复证据和提高置信均拒绝，避免模型重复生成长SQL/原文造成截断或复制失真。

最终报告只汇总固定范围此前成功 analysis，失败/取消仅列未完成；后端排除 SQL、附件与检索权限，不打开历史文件。允许批准脚本仅计算范围内登记证据。成功与结果同事务保存，result_file_path 初始为空，Markdown/HTML 初始 not_generated；页面展示和复制数据库正文，物理导出由 M06 完成。

工具记录实际参数、脚本版本、授权输入引用；stdout 保存任务output文件、SHA-256、生成时间，聚合 derived、文本检索保守 input_copy。命令默认关闭，管理员启用批准清单才开放。

Docker 仅 worker 通过可信 SSH 隧道或 Unix socket 访问。预载固定镜像 `python@sha256:cb33f7f771ecec2ef1225cf39b159591a040391bd73e4c01f00fdfc4c47611d2`；Compose worker 需Docker socket组，当前VM GID995，其他主机设 BA_DOCKER_GID。沙箱 UID10001、只读根、只读专用输入卷、16MiB output/8MiB tmp tmpfs、无网络、drop ALL、no-new-privileges、256MiB内存及交换上限、32进程、0.5CPU；不传密钥或挂载主机目录。取消/超时先确认杀进程、删除容器/卷，再释放槽位；启动清理仅本数据库标签下遗留资源。

M03 清单契约：`workspace/{user}/{conversation}/parsed/{attachment}/manifest.json` 包含 attachment_id、parse_options、files；files 项包含 relative_path（受控单文件名）、format（json/text）、position。任务只复制接受快照授权的安全输入，原名映射在本任务manifest；缺清单明确拒绝，不读原件绕过。上传、选择、真实模型读取和实际删除链路均已联调。
