## 字段与类型

以下定义与真实导入脚本一致。PRIMARY KEY 为业务主键，REFERENCES 为真实外键，NOT NULL 为必填，其他非主键字段可空。ID 均为字符串，不得转数值；occurred_at/registered_at/snapshot_at/created_at/paid_at/requested_at/completed_at 是带时区时间；attributed_date/period_start 是业务日期。price/amount/paid_amount/revenue 是人民币金额，quantity 是件数，score 是 1—5 分，status 是业务状态，device 是设备，channel/channel_id 是渠道，segment 是客户分组。

### 商品目录优化（catalog）

`catalog.categories`

```sql
category_id text PRIMARY KEY, name text NOT NULL
```

`catalog.products`

```sql
product_id text PRIMARY KEY, category_id text REFERENCES catalog.categories, name text NOT NULL, price numeric(12,2) NOT NULL
```

`catalog.search_impressions`

```sql
event_id text PRIMARY KEY, product_id text REFERENCES catalog.products, user_id text NOT NULL, keyword text, occurred_at timestamptz NOT NULL
```

`catalog.clicks`

```sql
event_id text PRIMARY KEY, impression_id text REFERENCES catalog.search_impressions, occurred_at timestamptz NOT NULL
```

`catalog.conversions`

```sql
conversion_id text PRIMARY KEY, click_id text REFERENCES catalog.clicks, order_id text NOT NULL, amount numeric(12,2), occurred_at timestamptz NOT NULL
```


### 客户行为分析（behavior）

`behavior.customers`

```sql
user_id text PRIMARY KEY, registered_at timestamptz NOT NULL, segment text
```

`behavior.visit_events`

```sql
event_id text PRIMARY KEY, user_id text REFERENCES behavior.customers, occurred_at timestamptz NOT NULL, device text NOT NULL, channel text
```

`behavior.cart_events`

```sql
event_id text PRIMARY KEY, user_id text REFERENCES behavior.customers, occurred_at timestamptz NOT NULL, device text, product_id text NOT NULL
```

`behavior.order_events`

```sql
event_id text PRIMARY KEY, user_id text REFERENCES behavior.customers, occurred_at timestamptz NOT NULL, device text, order_id text UNIQUE, amount numeric(12,2), status text NOT NULL
```


### 库存异常分析（inventory）

`inventory.stocks`

```sql
snapshot_id text PRIMARY KEY, product_id text NOT NULL, warehouse_id text NOT NULL, snapshot_at timestamptz NOT NULL, quantity integer NOT NULL
```

`inventory.inbound`

```sql
document_id text PRIMARY KEY, product_id text NOT NULL, warehouse_id text NOT NULL, occurred_at timestamptz NOT NULL, quantity integer NOT NULL
```

`inventory.outbound`

```sql
document_id text PRIMARY KEY, product_id text NOT NULL, warehouse_id text NOT NULL, occurred_at timestamptz NOT NULL, quantity integer NOT NULL
```

`inventory.sales`

```sql
sale_id text PRIMARY KEY, outbound_id text REFERENCES inventory.outbound, product_id text NOT NULL, warehouse_id text NOT NULL, occurred_at timestamptz NOT NULL, quantity integer NOT NULL
```


### 评论反馈分析（feedback）

`feedback.products`

```sql
product_id text PRIMARY KEY, name text NOT NULL
```

`feedback.reviews`

```sql
review_id text PRIMARY KEY, product_id text REFERENCES feedback.products, user_id text NOT NULL, order_id text NOT NULL, occurred_at timestamptz NOT NULL, content text
```

`feedback.ratings`

```sql
rating_id text PRIMARY KEY, review_id text REFERENCES feedback.reviews, score integer CHECK(score BETWEEN 1 AND 5), occurred_at timestamptz NOT NULL
```

`feedback.refunds`

```sql
refund_id text PRIMARY KEY, review_id text REFERENCES feedback.reviews, order_id text NOT NULL, amount numeric(12,2), reason text, completed_at timestamptz NOT NULL
```


### 市场表现分析（market）

`market.channels`

```sql
channel_id text PRIMARY KEY, name text NOT NULL
```

`market.ad_spend`

```sql
spend_id text PRIMARY KEY, channel_id text REFERENCES market.channels, campaign_id text NOT NULL, attributed_date date NOT NULL, amount numeric(12,2) NOT NULL
```

`market.orders`

```sql
order_id text PRIMARY KEY, user_id text NOT NULL, created_at timestamptz NOT NULL, paid_at timestamptz, status text NOT NULL, channel_id text REFERENCES market.channels, paid_amount numeric(12,2) NOT NULL, currency text NOT NULL
```

`market.sales_summary`

```sql
summary_id text PRIMARY KEY, channel_id text REFERENCES market.channels, period_start date NOT NULL, currency text NOT NULL, order_count integer NOT NULL, revenue numeric(12,2) NOT NULL
```


### 退款模式分析（refund）

`refund.customers`

```sql
user_id text PRIMARY KEY, segment text, registered_at timestamptz NOT NULL
```

`refund.orders`

```sql
order_id text PRIMARY KEY, user_id text REFERENCES refund.customers, paid_at timestamptz NOT NULL, paid_amount numeric(12,2) NOT NULL, currency text NOT NULL
```

`refund.reasons`

```sql
reason_code text PRIMARY KEY, description text NOT NULL
```

`refund.requests`

```sql
request_id text PRIMARY KEY, order_id text REFERENCES refund.orders, reason_code text REFERENCES refund.reasons, requested_at timestamptz NOT NULL, completed_at timestamptz, status text NOT NULL, amount numeric(12,2) NOT NULL
```

## 关联与统计语义

- catalog：categories → products → search_impressions → clicks → conversions；通过曝光、点击外键追踪成交，user_id 是业务用户。
- behavior：customers 关联访问、加购、下单事件；同用户同一期严格时间链，paid/completed 有效，按当期首次访问设备互斥归属。独立阶段去重不等于严格漏斗。
- inventory：按 product_id/warehouse_id 与时间对齐库存及入出库；sales.outbound_id 关联出库单。
- feedback：products → reviews → ratings/refunds；user_id/order_id 关联业务来源。
- market：channels 关联投放、订单及汇总；先按 order_id 去重，按 paid_at 归期，投放先按渠道/日期聚合再关联。sales_summary 只用于核对，不能与明细累加。
- refund：customers → orders → requests，reason_code 关联 reasons；申请与完成时间分开统计。

## 导入与隔离

PowerShell 设置 `$env:PYTHONPATH="backend"` 后运行 `uv run --locked python -m app.sample_data`。脚本仅初始化专用 ba_demo；固定主键及 ON CONFLICT DO NOTHING，重复执行不清空、不覆盖、不叠加、不重置既有密码。导入产生数据源草稿，管理员测试并重载后生效。行数为干净库基准，不表示会删除已有扩展数据。

六个 schema 分别有独立只读角色，仅授予样例库 CONNECT、对应 schema USAGE/SELECT。拒绝写入、跨 schema 和应用运行库访问。管理员账号只用于导入，不交给分析工具。

## 复算与边界

基准 SQL：samples/queries/behavior.sql、market.sql、market-quality.sql、other-scenarios.sql；边界集 samples/boundaries.json 独立于演示数据。两条逐轮输入、补充附件及基准答案见 [演示说明](../samples/demos/README.md)。

真实数据库测试验证 25 表非空、关联查询、两次导入不叠加、只读及隔离；漏斗边界含跨设备、重复、跨期、缺步骤与同时间戳，市场边界含取消/未支付、跨期支付、缺 paid_at、重复冲突、未归因和无订单渠道。完整真实模型分析与动态报告仍由后续模块验收。
