# 工作台整页空白滚动修复

结论：专项修复验证通过。当前开发页面已生效，前端构建通过；未更新虚拟机交付实例。[机器结果](测试结果.json)。

## 原因和变更

结果底部保留了一段 `.sr-only` 辅助说明。它采用绝对定位，原工作台根节点没有建立定位参照，长结果下该元素的静态位置落在可视范围之外，浏览器将其计入document可滚动范围。真实会话73中，视口1000px、工作台本身1000px，document滚动高度却达到2525px，因此可以滚到大块空白。

仅在 `frontend/src/workbench.css` 的 `.wb` 上增加 `position:relative`，让现有一屏高度和overflow边界约束绝对定位后代。消息区、结果区保持各自滚动；不修改全局body滚动、输入框位置、辅助文字或业务逻辑。
