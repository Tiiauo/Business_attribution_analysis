# 工作台工具过程默认折叠

结论：本次专项验证通过，开发环境已生效，前端构建通过；虚拟机交付实例尚未更新。[机器结果](测试结果.json)。

## 变更

根据用户当前截图和确认意见，将逐条铺开的工具卡片合并为每轮一个默认折叠入口，显示轮次、调用数量及工具失败次数，点击“查看过程”展开，原有状态与脱敏记录仍可继续查看。移除正常分析底部重复的同轮过程摘要。市场分析的当前轮与更早轮次复用相同入口。

运行中保留当前步骤、执行中的工具、流式正文和取消入口，已结束工具收在折叠区。取消受理期间继续占位，确认终态后转为默认折叠的历史过程。失败原因与部分回答不收入工具折叠区，现有发送与原请求重试入口保持原行为；不增加自动重新分析或模型调用。

一并修复加载历史按钮缺少滚动对齐目标、会被后续消息吸附顶出可点击区域的问题。历史页缺少对应提问时显示“较早轮次”，加载更早消息后合并同任务记录并更新轮次，不重复展示。原有归档历史总入口、证据、导出及数据库内容保留。
