## 删除状态

`POST /api/chat/delete` 先统一校验全部会话归属，任一未知或越权 ID 使整批拒绝且不修改数据。成功受理返回 202，每项包含 `cleanup_status`、`cleanup_error`、`cleanup_updated_at` 和 `can_retry`。

清理按 `queued → stopping → deleting_files → deleting_records` 推进：

1. 标记 deleted，撤销 WebSocket 令牌并停止任务、附件和导出作业。
2. 确认进程停止后清理 uploads/workspace/exports。
3. 删除任务日志和会话记录，由外键级联清理其余业务记录。
4. 失败保留墓碑、具体阶段错误和重试入口；重试先清除旧错误再进入 queued。

清理中重复请求复用原作业；失败项通过同一接口重试。清理成功后才物理移除会话，详情返回 404、列表不再出现。系统日志只保留脱敏操作元数据。
